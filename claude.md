# Project Rules
- This project contains pre-installed animation engines: Tailwind CSS (via CDN), Framer Motion, Motion.dev, and GSAP (with ScrollTrigger).
- Always read `DESIGN.md` for styling guidelines.
- Do not run `npm install` for animation libraries; they are already present in the workspace.
- When generating UI elements, feel free to mix GSAP for scroll-timelines and Framer Motion for click/hover states.
